This file is a **template**, not a published post. It stays hidden from the site
because `draft: true`.

To publish your first post: copy this file, rename it (e.g. `my-first-post.md`),
fill in the frontmatter above, set `draft: false`, and write your post in Markdown
here. It will show up automatically on the Writing page.
